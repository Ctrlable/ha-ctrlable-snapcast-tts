How routing works

  1. When an ESP32 says the wake word, HA Assist fires a TTS announce event with the satellite's device name
  2. The add-on looks up the satellite + wake word (or the * wildcard row) in this table
  3. Audio streams to the matched Snapcast client(s) — source switches temporarily, then restores
